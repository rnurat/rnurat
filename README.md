## Привет, я Мурат — backend-инженер

Пишу на **Laravel** и **Symfony**, проектирую REST API, которые не ломаются под нагрузкой.  
Моя тема — разгребать легаси, покрывать тестами и собирать из хаоса системы, за которые не стыдно.  
Сейчас ищу команду, где бэкендер решает архитектурные задачи, а не просто закрывает тикеты.
